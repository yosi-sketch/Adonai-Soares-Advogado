# Dra. Paloma Fernandes — Advocacia Previdenciária INSS

Landing page institucional e de alta conversão para o escritório **Dra. Paloma Fernandes — Advocacia Previdenciária INSS**, especializado em Direito Previdenciário (Planejamento Previdenciário, Aposentadorias Urbanas e Rurais, Benefícios por Incapacidade, BPC/LOAS e Pensão por Morte), com sede na Av. Gov. Milton Campos, 2973 - Sala 204 - Centro, Guanhães - MG e atendimento digital em todo o Brasil.

## Tecnologias

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4** (com tokens customizados e tema inline)
- **Framer Motion 13**
- **Lucide React**
