# Dra. Janaína Carvalho — Advogada

Landing page institucional e de alta autoridade para o escritório **Dra. Janaína Carvalho — Advogada**, especializado em Direito de Família e Sucessões (Divórcio em Cartório e Judicial, Guarda e Convivência, Pensão Alimentícia, Partilha de Bens e Inventários), com sede na Praça Pref. Mário Carneiro, nº 50 - 2º andar - sala 01 - Centro, Dores do Indaiá - MG e atendimento digital em todo o Brasil.

## Tecnologias

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4** (com tokens customizados e tema inline)
- **Framer Motion 13**
- **Lucide React**
